## Public abstract

We will publish the latest Agent Infra and Model Infra landscapes, recording new projects, category changes and ecosystem signals. This time, the maps also provide the entry point to the research sample. These Agentic AI projects are young, highly visible and form a dense engineering testbed for autonomous software systems.

The study asks a question that is already affecting software development: when AI starts writing code and working with Issues and pull requests, what happens to open-source collaboration?

## Research section to build next

The study will examine roughly one hundred post-2024 Agentic AI repositories and a matched group of traditional software repositories. The comparison needs equivalent repository-age windows and controls for language, ownership, contributor scale and pull-request volume.

The first research question is whether AI participation improves collaborative throughput or mainly increases code output while moving more review and judgment onto maintainers. Supporting questions should measure:

- whether repository openness is reflected in accepted outside contributions;
- how review latency, revision rounds and merge outcomes change;
- whether maintainer workload and contributor concentration rise or fall;
- where collaboration moves when core Issues or pull requests are closed;
- how machine-readable contribution instructions affect agent and human participation.

DeepSeek Harness is a useful opening case because public code, accepting external pull requests and developing a plugin ecosystem are three separate project choices. It should introduce the research question, not stand in for the full sample.

## Evidence boundary

A pull request must not be labelled AI-generated without explicit public evidence. Bot accounts, automation and human contributors should be separated. Results should report distributions and matched comparisons, not only totals or a few visible repositories.

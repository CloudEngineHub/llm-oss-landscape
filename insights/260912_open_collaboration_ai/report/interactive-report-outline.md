# 260910 interactive research report

> Interaction notes for the web edition. The canonical report narrative is `online-report.md` in this directory.

Reference for the reading experience: <https://stateofopensource.ai/>

The report should work as an online research publication rather than a transcript of either talk. Readers need to move between the ecosystem map, the research method, repository evidence and individual cases without following a fixed five- or ten-minute sequence.

## Proposed reading path

1. The current Agent Infra and Model Infra maps, with the latest additions and classification decisions.
2. What changed in the ecosystem and what the signals can establish.
3. What agents require from open infrastructure.
4. The repository study: sample, controls, metrics and limitations.
5. Findings on contributions, review, maintainer workload and where collaboration takes place.
6. Cases that complicate the aggregate result, including DeepSeek Harness.
7. Implications for internal software-development and deployment governance.

This ordering is provisional. The final structure should follow the strongest finding rather than preserve the presentation agenda.

## Quote handling

The release will include a CTO quote and a chair quote. Until approved text is available, the page should contain no fabricated quotation, paraphrase or implied endorsement. Each quote needs the speaker's approved title, final wording and confirmation of where it may be published.

## Interaction principles

- Every chart should expose its metric definition and comparison window nearby.
- Landscape exploration, report reading and presentation playback are separate modes.
- GitHub attention signals and production evidence must use different visual labels.
- Repository cases should link to the exact Issue, pull request, contribution guide or setting used as evidence.
- Mobile readers should be able to reach the main finding without loading the full landscapes first.

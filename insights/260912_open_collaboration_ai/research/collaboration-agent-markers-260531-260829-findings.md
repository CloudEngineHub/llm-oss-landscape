## 自我质疑与替代解释

- 两个历史快照都使用当前 Top 100 样本。这是一个受存活状态和当前热度共同约束的面板，不能代表 5 月当时全部仓库。
- 扫描范围使用预先声明的仓库根目录和 `.github` 目标路径。项目可能把有效指令放在更深层目录；重复使用同一组路径，使变化比较比绝对覆盖率更稳定。
- 新增指令文件可能只是把此前私下进行的工作流公开记录下来。观察日期表示扫描路径中首次出现公开标记的时间，不一定是真正的首次采纳日期。
- 工具标记消失可能意味着迁移、合并进跨 Agent 指令文件，或路径移动。每个“移除”都保留为人工复核候选，不能自动解释为放弃使用。
- 仓库的 Agent 准备度可能上升，但 Agent 在公开 Issue 和 PR 中的参与仍然很低。协作线程研究需要直接检验这种可能性。

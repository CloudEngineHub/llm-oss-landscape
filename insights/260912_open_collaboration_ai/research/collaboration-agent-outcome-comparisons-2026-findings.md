# 可见 Agent 参与和线程结果的比较

状态：只做描述。Agent 不是随机进入线程的，也可能在任务变难以后才被引入。

- 获得足够观察期的样本中，有 45 条由可确认 Agent 身份或 App 代理行为发起，2630 条由 GitHub `User` 发起。两类身份在 actor registry 中分开保存。
- 概率样本中有 12 个仓库同时出现两类发起者。
- 在仓库内部比较，Agent 发起减去 GitHub User 发起的 open share 差值中位数是 -0.0156。

这些数据可以看 Agent 参与集中在哪里，是否同时伴随更多 review 或更慢处理；不能证明效率效果。要做因果估计，需要随机分配、可信的 adoption 断点，或者比当前公开轨迹更强的前趋势和选择控制。

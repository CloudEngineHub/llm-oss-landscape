# Awesome × Agentic AI curated projects

`projects.csv` is the formal, strictly curated project list used by the Awesome × Agentic AI landscape.

The registry started with the 26 projects selected on 2026-07-29. Later Trending repositories are added individually only when the repository itself delivers reusable curation, skills, plugins, templates, playbooks, or agent working methods. Discovery pools are never merged into this file automatically.

Current categories are intentionally simple:

- `Curated collections`
- `Skills & plugins`
- `Domain playbooks`
- `Workflows & methods`

Time-varying metrics retain their source snapshot date. `projects.csv` is a selected registry, not a complete census of Awesome or Agentic AI repositories.

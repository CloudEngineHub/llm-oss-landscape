How to read these signals

CORE / WATCH / BASELINE is an editorial role. CORE anchors the argument, WATCH is promising but needs another window, and BASELINE shows the older human-browsed form.

Direct / hybrid / indirect describes agent consumability: whether the repository already packages executable assets, mixes assets with human-oriented curation, or mainly serves human browsing.

WatchEvents counts visible GitHub watch/star events in the observed window. Coverage limits mean it must not be presented as exact star growth.

Participants counts distinct issue and pull-request participants. OpenRank summarizes network activity; neither is a quality verdict by itself.
